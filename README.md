# 📡 Cuestionario COM - 2do Parcial

Simulador interactivo de preguntas para el **2do Parcial de Comunicaciones (COM) - UTN**.

Desarrollado en un único archivo HTML autocontenido (sin dependencias externas, funciona offline).

---

## ✨ Características

- 🌙 **Modo Oscuro (Dark Theme):** Diseño moderno, elegante y de alto contraste.
- 📋 **122 Preguntas Únicas:** Sin preguntas repetidas, extraídas y consolidadas de los parciales y cuestionarios anteriores.
- 🎯 **Múltiples Formatos de Respuesta:**
  - Selección única (Radio buttons)
  - Selección múltiple (Checkboxes)
  - Verdadero / Falso
  - Respuesta escrita / Completar campo de texto (con tolerancia a mayúsculas, minúsculas, tildes y espacios)
- 🔀 **Aleatoriedad configurable:**
  - Interruptor para mezclar preguntas
  - Interruptor para mezclar el orden de las respuestas
- ⬅️ ➡️ **Navegación completa:** Botones de Anterior y Siguiente para revisar y navegar entre preguntas sin perder tus selecciones.
- ⭐ **Sistema de Marcado (Favoritas / Para Repasar):** Marca preguntas con estrella y practícalas por separado.
- 🔄 **Reintento de Errores:** Practica únicamente las preguntas en las que te hayas equivocado.
- 📦 **Práctica por Bloques:** División en bloques de 10 preguntas para estudiar por partes.
- ⌨️ **Atajos de teclado:**
  - `←` : Pregunta anterior
  - `→` : Pregunta siguiente
  - `Enter` : Verificar respuesta / Avanzar a la siguiente pregunta
  - `1` - `9` : Seleccionar opciones numéricamente
- 📊 **Resultados y Estadísticas:** Puntuación final con porcentaje, desglose de aciertos y errores.

---

## 🚀 Cómo usar

1. Descarga o clona este repositorio:
   ```bash
   git clone https://github.com/andy-T-22/COM-segundo-parcial.git
   ```
2. Abre el archivo `index.html` (o `cuestionario_com.html`) en cualquier navegador web (Chrome, Edge, Firefox, etc.).
3. ¡Listo para practicar!
